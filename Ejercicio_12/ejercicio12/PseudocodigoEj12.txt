Consultar hechizos prohibidos:
Se hace el recorrido inorden del árbol binario de búsqueda de hechizos consultando en cada nodo si el id de ese nodo deja resto distinto de cero en la división entre dos (números impares, hechizos prohíbidos), si es el caso, se agrega ese hechizo a una lista inicialmente vacía. Después de que se recorra todo el árbol se devuelve la lista con todos los hechizos cuyo id es impar.

Precondiciones:
-Árbol binario de búsqueda no null.
-Cada nodo no nulo del árbol tiene el id (int) y el nombre (string) del hechizo.

Postcondiciones:
-Debe devolver una lista con los hechizos prohibidos, ordenados de menor a mayor según el id del hechizo (se hizo un recorrido inorden).
-El árbol no debería haber sido modificado.

Pseudocódigo:
Lista listaHechizosProhibidos <- nueva Lista vacia
Lista consultarHechizosProhibidos(NodoÁrbol nodo) {
	si nodo==null
		devolver listaHechizosProhibidos
	fin si
	si nodo.hijoIzquierdo<>null hacer
		nodo.hijoIzquierdo.consultarHechizosProhibidos
	fin si
	si nodo.id %2 <>0 hacer
		listaHechizosProhibidos.agregar(nodo)
	fin si
	si nodo.hijoDerecho<>null hacer
		nodo.hijoDerecho.consultarHechizosProhibidos
	fin si	
	devolver listaHechizosProhibidos	
}


Análisis de tiempo de ejecución: es de complejidad O(N), porque se ejecuta tantas veces como nodos haya en el árbol, se va analizando cada uno de los nodos del árbol verificando si su id es divisible o no entre dos y agregándolo o no a la lista.




Generar cántico:
Se hace el recorrido inorden del árbol binario de búsqueda de hechizos consultando en cada nodo si el id de ese nodo deja resto distinto de cero en la división entre 2 (números impares/ hechizos prohibidos), si es el caso, se concatena el nombre de ese hechizo a una cadena inicialmente vacía. Después de que se recorra todo el árbol se devuelve la cadena con todos los hechizos cuyo id es impar.

Precondiciones:
-Árbol binario de búsqueda no null.
-Cada nodo no nulo del árbol tiene el id (int) y el nombre (string) del hechizo.

Postcondiciones:
-Debe devolver una cadena con los hechizos prohibidos separados por un guion, ordenados de menor a mayor según el id del hechizo (se hizo un recorrido inorden).
-El árbol no debería haber sido modificado.

	devolver cadenaHechizosProhibidos	
}


Análisis de tiempo de ejecución: O(N), porque se ejecuta tantas veces como nodos haya en el árbol, se va analizando cada nodo del árbol viendo si su id es divisible o no entre 2 y concatenándolo o no a la String.
